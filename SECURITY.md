# Security Policy

This repository contains public community documentation and illustrative data schemas, not the SignalHub application source code.

## Reporting a vulnerability

Do **not** open a public GitHub Issue for a security vulnerability affecting SignalHub, its users, or associated infrastructure. Send a private report to **info@vulnhero.com**, subject **SignalHub Security Report**. Include affected component, impact, safe reproduction details, and contact information. Do not include live secrets or exploit third-party systems.

Receipt, resolution timelines, or rewards are not guaranteed by this document. Please allow time for private review and coordinated disclosure.

## Supported artifacts

Documentation and example schemas may be updated. This file does not assert a bug bounty program.
